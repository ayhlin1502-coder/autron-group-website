# Autron Group Website

Next.js 14 App Router foundation with TypeScript and Tailwind CSS.

## Development

```bash
npm install
npm run dev
```

The local site runs at `http://127.0.0.1:3100`.

## Verification

```bash
npm run lint
npm run typecheck
npm run build
npm run test:e2e
```

The primary brand colour is intentionally left as `CONTENT REQUIRED` until the logo is confirmed. Design tokens are defined in `tailwind.config.ts` and `src/app/globals.css`.
