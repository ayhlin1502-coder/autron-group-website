# Autron Group 澳創集團官方網站 — Master Build Prompt

（此檔案為使用者提供之原始完整需求規格，逐字保存，作為 Claude Code 專案的權威依據。與 01-PLANNING.md、CLAUDE.md 一併放在專案根目錄。)

請為「澳創集團 Autron Group」規劃、設計並建立一個完整、專業、現代、具有國際企業質感的官方集團網站。

這不是單一產品品牌網站，也不是一般傳統貿易公司官網，而是一個：

Corporate Group Portal + Business Lead Generation Platform + Long-term Digital Asset

網站需同時承擔以下角色：
1. 建立 Autron Group 澳創集團整體品牌形象
2. 清楚呈現集團旗下主要事業與品牌
3. 讓不同類型客戶快速找到適合的服務
4. 將流量有效分流到：Autron Trade / AuzCare / Autron Go / Quarter Innovation
5. 建立澳洲、台灣及全球市場之間的跨境商業定位
6. 支援未來新增品牌、產品、服務、市場與新事業
7. 建立 B2B 商業合作、品牌代理、經銷、物流與科技服務詢問入口
8. 同時兼顧 SEO、AI Search、網站資安、效能與未來擴充性

網站整體感受：Professional / International / Premium / Modern / Innovative / Trustworthy / Clean / Corporate / Entrepreneurial / Scalable
不要設計成：傳統老派貿易公司網站 / 單純商品型網站 / 過度科技新創風格 / 過度花俏的 Creative Agency 網站

## 17. FULL BILINGUAL SYSTEM
第一版起完整支援繁體中文/English，任何頁面可自由切換（如/zh-tw/autron-trade ↔ /en/autron-trade），不可切換後跳回首頁。系統記住語言Preference，不用IP強制Redirect。獨立語言URL，各語言版本獨立Content/SEO Title/Meta Description/OG/URL。正確使用hreflang（zh-Hant-TW/en/x-default）。CMS所有主要欄位支援雙語，翻譯缺少顯示「Translation Missing」，可預留AI Translation Draft但須人工Review後才Publish。

## 18. VISUAL CMS + DRAG & DROP PAGE BUILDER
後台不可只是文章CMS，須支援Visual CMS + Drag-and-Drop Section Builder。管理者可修改Text/Headline/Image/Video/Button/Link/CTA/Background/Icon/Numbers/Contact Information，可Drag/Reorder/Duplicate/Hide/Delete/Add Sections。可用Section：Hero/Text+Image/Full Width Image/Business Cards/Services/Brands/Products/Map/Timeline/Statistics/Logo Wall/Video/CTA/News/FAQ/Contact Form。

## 19. DESIGN SYSTEM LOCK
不做完全自由的Wix-style Free Canvas，採Design System + Reusable Components + Drag-and-Drop Sections。管理者可自由排列Section但不可破壞Typography/Spacing/Grid/Brand Colours/Button Style/Mobile Layout。建立Global Typography/Colours/Buttons/Spacing/Grid/Cards/Icons，管理者選Preset Styles而非直接改Raw CSS。

## 20. CMS FEATURES
支援Draft/Preview/Publish/Unpublish/Scheduled Publish；Preview含Desktop/Tablet/Mobile；支援Revision History+Rollback（至少30版本或90天）；建立Global Components（Header/Footer/Global CTA/Contact Form/Business Navigation/Partner Logos/Global Network），修改後所有頁面同步更新。

## 21. CMS USER ROLES
Super Admin/Administrator/Editor/Marketing/Viewer，採Role-Based Access Control。Super Admin所有權限；Marketing可改內容但不可改核心Security與帳號/系統設定；Viewer只能預覽。

## 22. CREATIVE DESIGN DIRECTION
需Professional/Premium/Modern/International/Innovative但保持企業可信度。方向：International Business Group × Modern Technology Company × Premium Corporate Brand。不要廉價Template/大量漸層/過度圓角/每區都是Card/大量Stock Photo/過度未來科技Neon Style。

## 23. MOTION & SCROLL EXPERIENCE
加入Smooth Scroll/Scroll-triggered Reveal/Text Reveal/Image Reveal/Horizontal Scroll/Sticky Storytelling/Subtle Parallax/Micro Interactions。首頁Four Businesses可用Sticky Scroll Story，向下Scroll依序Autron Trade→AuzCare→Autron Go→Quarter Innovation，視覺跟著轉換。Global Map可用Animated Trade Routes（Australia↔Taiwan→China→USA→Japan→Vietnam），Hover Country顯示Market/Business Type/Activities，不可將目標市場假裝成辦公室。

## 24. MOTION PERFORMANCE RULE
所有動畫Subtle/Fast/Purposeful，建議200ms–600ms。不要Heavy 3D/Long Intro/大型自動播放背景影片/Autoplay Sound/過度Parallax。須支援prefers-reduced-motion，設定Reduce Motion時自動降低或取消Parallax/Complex Scroll Motion/Heavy Animations。

## 25. DESIGN SYSTEM
色彩依Autron Group Logo建立：Primary=Logo Main Colour；Secondary=Deep Navy/Charcoal；Background=White/Off White/Light Grey。字體：英文Inter/Manrope/DM Sans或同等Sans Serif；繁中Noto Sans TC。Headline Bold/Large/Clean；Body高可讀性。

## 26. MOBILE EXPERIENCE
Mobile First，不可只是Desktop縮小。需Hamburger Navigation/Vertical Cards/Responsive Typography/Large Tap Targets/Simplified Animation/Optimised Images。Horizontal Scroll在手機版須自然、容易操作、不影響閱讀。

## 27. SEO ARCHITECTURE
從Architecture階段實作。每個主要頁面Server-Side Rendered或Static Generated，建議Next.js SSR/SSG/ISR，重要內容不可完全依賴Client-side JavaScript才出現。

## 28. CORE WEB VITALS
目標：LCP≤2.5s / INP<200ms / CLS<0.1。Animation不可破壞Core Web Vitals。需Image Optimisation（WebP/AVIF/Responsive Images/Lazy Loading）、Font Optimisation、Code Splitting、Caching、CDN、Compression，Above-the-Fold Assets優先載入。

## 29. ON-PAGE SEO
每頁後台可管理SEO Title/Meta Description/URL Slug/Canonical URL/OG Title-Description-Image/Index-Noindex。每頁清楚H1/H2/H3，只用一個主要H1，使用Semantic HTML（header/nav/main/section/article/footer）。

## 30. STRUCTURED DATA
依頁面內容實作Schema.org：Organization/WebSite/BreadcrumbList/Service/Product/Brand/Article/FAQPage/LocalBusiness，只有實際符合時使用，不可建立與頁面實際內容不符的Structured Data。

## 31. SITEMAP & ROBOTS
自動建立sitemap.xml（含中英文頁面/Business Pages/Brands/Products/News），自動更新。建立robots.txt，CMS/Admin/Preview/Staging不得被Index。

## 32. INTERNAL LINKING
建立清楚Entity Architecture：Autron Group→Business Unit→Services→Products→Markets（例：Autron Group→Autron Trade→Australian Products→Taiwan Market），避免Orphan Pages。

## 33. IMAGE SEO
所有重要圖片需ALT Text/Descriptive Filename/Responsive Sizes，CMS可編輯ALT Text。

## 34. GOOGLE / SEARCH TOOLS
預留整合Google Search Console/GA4/GTM/Bing Webmaster Tools，Tracking不得破壞Privacy與Performance。

## 35. AI SEARCH READINESS
兼顧Google AI Overviews/Generative Search/Answer Engines/AI Assistants。內容須Clearly Structured/Entity Based/Factually Consistent/Easy to Crawl/Easy to Reference。每個Business Page應清楚回答：Who are you? What do you do? Where do you operate? Who do you serve? What services do you provide? How can customers contact you? Entity Relationship：Autron Group→Autron Trade/AuzCare/Autron Go/Quarter Innovation。

## 36. SECURITY BASELINE
依目前Web Application Security Best Practices建置，最低基準OWASP Top 10:2025，並以OWASP ASVS 5.0作為Security Verification Framework。

## 37. HTTPS & TLS
Production HTTPS Only，最低TLS 1.2，Prefer TLS 1.3，HTTP自動Redirect HTTPS。

## 38. SECURITY HEADERS
實作Content-Security-Policy/Strict-Transport-Security/X-Content-Type-Options/Referrer-Policy/Permissions-Policy/Frame Protection，防範Clickjacking/MIME Sniffing/Unsafe Embedding。

## 39. CMS SECURITY
CMS Login支援MFA/Strong Password Policy/Rate Limiting/Session Timeout/Login Protection，可預留Passkeys，Admin系統不可暴露不必要資訊。

## 40. API SECURITY
所有API需Authentication/Authorization/Rate Limiting/Input Validation/Output Encoding，所有權限採Least Privilege Principle。

## 41. INPUT SECURITY
Contact Form/Search/CMS/API必須防護SQL Injection/Cross-Site Scripting/CSRF/Command Injection/File Upload Attacks，所有Validation須Server-side。

## 42. DATABASE SECURITY
Database Account最低必要權限，敏感資料不得Plain Text儲存，Password Hash用Argon2id或同等現代標準。

## 43. SECRET MANAGEMENT
API Keys/Database Credentials/Authentication Secrets不可寫入Frontend或Git Repository，使用Environment Variables或Secret Management Service。

## 44. DEPENDENCY SECURITY
建立Dependency Scanning/Vulnerability Alerts/Automated Updates（如Dependabot），第三方Package限制數量、定期更新、Lock Versions、監控CVE。

## 45. CONTACT FORM SECURITY
表單加入Bot Protection/Rate Limiting/CSRF Protection/Server-side Validation，可用Cloudflare Turnstile，避免過度侵入式Captcha。

## 46. LOGGING & AUDIT
記錄Authentication Logs/Admin Actions/Permission Changes/Publish Actions/Security Events，不可記錄Passwords/Auth Tokens/Sensitive Payment Information。

## 47. BACKUP & DISASTER RECOVERY
Database Automated Backup（建議Daily），需可測試Restore Procedure，建立Database Recovery/CMS Recovery/DNS Recovery流程。

## 48. STAGING ENVIRONMENT
Production與Staging完全分離，Staging須Password Protected + Noindex，不可公開Test Data。

## 49. PRIVACY
Contact Form只蒐集必要資料。建立Privacy Policy/Cookie Policy。若使用GA/Meta Pixel/Advertising Pixels須規劃Cookie Consent。個資不得無限期儲存，須建立Data Retention Policy與Access Control。

## 50. ACCESSIBILITY
以WCAG 2.2為設計基準。要求Keyboard Navigation/Focus State/Colour Contrast/Accessible Forms/Alt Text/ARIA Labels/Semantic HTML/Reduced Motion。

## 51. CMS / PLATFORM RECOMMENDATION
優先評估Storyblok/Builder.io/Sanity/Payload CMS/Strapi，評估重點：Visual Editor/Drag & Drop/Multilingual/Permissions/Version History/Preview/Security/API Flexibility。不要用只能改文字但無法管理Section Layout的Basic CMS。

## 52. TECH STACK
Frontend：Next.js/React/TypeScript/Tailwind CSS。CMS：Modern Headless/Visual CMS。Hosting：Vercel/Cloudflare/AWS或同等平台。CDN：Global CDN。Security：WAF/DDoS Protection/Bot Protection/Rate Limiting。Animation：GSAP/Framer Motion/CSS Animation/Web Animations API，但不要濫用。

## 53. CONTENT RULES
不可自行創造Revenue/Employee Count/Founded Year/Office Locations/Customers/Distribution Rights/Brand Rights/Certifications/Market Presence/Logistics Capability。資料未提供使用[CONTENT REQUIRED]。不可把洽談中合作寫成已合作、目標市場寫成已有辦公室、合作製造商寫成代理品牌、概念產品寫成正式上市。醫療/蜂蜜/蜂膠/保健相關內容避免未經確認醫療或療效宣稱。

## 54. CMS DATA COLLECTIONS
建立CMS Collections：Businesses/Brands/Products/Services/Markets/Distribution Channels/News/Case Studies/Partners/CTA/Contact Details，每個Collection支援中文/英文/SEO/Status/Featured Image/Publish Date。

## 55. LEAD GENERATION
每個Business Page使用不同CTA：Autron Trade（Discuss a Trading Opportunity）、AuzCare（Become a Brand Partner）、Autron Go（Request a Freight Quote）、Quarter Innovation（Start a Project）、Global（Partner With Autron）。不要每頁全部都是Contact Us。

## 56. ANALYTICS & CONVERSION TRACKING
追蹤CTA Click/Contact Form Start/Contact Form Submission/Business Page Visits/Language Switching/External Partner Link Clicks，透過GA4/GTM建立Conversion Events。

## 57. PERFORMANCE PRIORITY
優先順序：1.Content 2.Usability 3.Conversion 4.Performance 5.SEO 6.Accessibility 7.Animation。任何Animation造成LCP/INP/CLS不良或Mobile Lag，必須簡化或移除。

## 58. QUALITY TARGET
上線前目標：Lighthouse Performance 90+/SEO 95+/Accessibility 90+/Best Practices 95+；Core Web Vitals LCP≤2.5s/INP<200ms/CLS<0.1；Security無Critical/High-Risk Vulnerabilities。

## 59. PRE-LAUNCH QA
上線前完成SEO Audit/Performance Audit/Accessibility Audit/Security Review/Mobile-Tablet-Desktop QA/Cross-Browser QA/Translation QA/Broken Link Check/Schema Validation/Sitemap Validation/Form Testing/Backup Testing。上線前移除Test Accounts、Disable Debug Mode、移除Demo Data、Rotate Development Secrets、Enable Backups/Monitoring/Security Logging。

## 60. DEVELOPMENT PRINCIPLE
不要做成「AI一次生成完成但難以維護的網站」。網站須是Scalable/Editable/Secure/SEO-ready/Multilingual/Conversion-focused的Long-term Corporate Digital Platform。Autron Group團隊未來須可自行新增品牌/產品/市場、修改Business Page、更換圖片、修改CTA、調整Homepage Section、建立Landing Page、管理中英文、新增新聞、發布Case Study，而不需每次找Developer。

## 61. PHASE 1 BUILD SCOPE
優先完成：Home/About/Autron Trade/AuzCare/Autron Go/Quarter Innovation/Global Network/Contact/Bilingual CMS/Visual Section Builder/SEO Foundation/Security Foundation。暫不做：Large E-commerce/Complex Member Area/ERP Integration/Large CRM/Distributor Portal/Supplier Portal。

## 62. REQUIRED OUTPUT BEFORE CODING
正式Coding前先提供：Final Sitemap/Homepage Wireframe/Desktop Navigation/Mobile Navigation/Homepage Section Structure/Individual Business Page Structure/Visual Design Direction/Animation Direction/Colour System/Typography System/CTA Architecture/Chinese Homepage Copy/English Homepage Copy/CMS Architecture/CMS Collections/Bilingual Architecture/SEO Architecture/Security Architecture/Recommended Technical Stack/Hosting Recommendation。（此20項已於 01-PLANNING.md 完成）不要直接進入Coding，先完成Planning，等設計與資訊架構確認後再開始正式建立網站。

## 63. FINAL BRAND EXPERIENCE
最終網站須讓訪客感受到：「Autron Group是一個以澳洲與台灣為基礎，正在連結亞洲與全球市場，擁有貿易、品牌經銷、物流與科技四項互補能力的現代跨境企業集團。」而非「一家同時賣很多不相關商品的小型貿易商。」須讓潛在合作夥伴感受到Professional/Reliable/International/Agile/Commercially Capable/Modern/Growth-Oriented。整個網站的設計、文字、互動、導航與CTA都須服務這個品牌定位。
